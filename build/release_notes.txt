WireTrace v2.2.0

Updates you notice and can undo, a tour of every part of WireTrace, and a diagnostic log to send with a report.

Added
- A tour, offered at the first start and kept in Help, on a sample board built in.
- Help > Return to version 2.1.0...: the earlier release, verified by signature. From this version on, your settings are copied before each update and put back on a return.
- A diagnostic log of WireTrace's own events, kept on this computer and never sent. Help copies a summary to paste into a report.
- An update found stays offered in the status bar until you install it, skip it or put it off.
- benchmarks.json with each release: WireTrace measured on GitHub's machines as the release is built.

Changed
- The plot uses less of the processor and still shows every spike.
- After an update or a return, the update check also says which version WireTrace changed from.

Fixed
- On Windows, a tab could stop showing new lines while its port stayed open. The lines are now picked up without reopening the port.
- On some computers, updates could not be downloaded. Certificates are now checked by the operating system.

Every change: CHANGELOG.md in the repository. Privacy: https://thenuanceproject.com/privacy/
