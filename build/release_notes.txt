WireTrace v2.1.0

Leave your boards running. When one is unplugged or resets its USB connection, WireTrace waits for the same board and carries on with the same session and the same log.

Added
- Reconnect: when WireTrace cannot be sure the board that came back is the same one, it asks. On by default; switched per tab in the Device menu.
- Line settings: data bits, parity, stop bits and flow control per port. While connected, set DTR and RTS and send a break; the status bar shows CTS, DSR, DCD and RI.
- The plot in a window of its own, back to the start of the session, saved as PNG or SVG, with its values as CSV.
- Restart detection for ESP32 and Zephyr boards, and a session report with exact counts of lines, errors, warnings, lost connections and restarts.
- Alerts on new error lines, a lost connection or a quiet board, with the system's sound and, if chosen, a desktop notification. Off by default.
- The console shows each line's date and time by default, as the log writes it.
- Highlight rules, and ANSI colours from the device on screen. Logs stay plain text.
- A Features page in Preferences: switch off what you do not use.

Fixed
- On Windows, an unplugged CH340 adapter could leave the session open, repeating "Access is denied". An error that leaves a port unusable now ends the connection at once.
- No part of a window appears on its own for a moment as it opens.

Every change: CHANGELOG.md in the repository. Privacy: https://thenuanceproject.com/privacy/
